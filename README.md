# Driftwood — винтажный аналоговый синт (VST3)

2 осциллятора с морфингом форм · саб + шум · X-Mod · **Drift** (живой плавающий строй) ·
фильтры Ladder (Moog/Juno) и MS (MS-20) · 2 огибающие · LFO с задержкой · Poly/Mono/Legato + Glide ·
Juno-хорус · Tape (wow/flutter, сатурация, «возраст») · Lo-Fi · эхо с синхронизацией · реверб · 17 пресетов.

## Как получить готовый плагин для Windows

### Вариант A — без установки компилятора (GitHub, ~10 минут)
1. Зарегистрируйся на github.com → **New repository** (можно приватный) → **uploading an existing file**.
2. Перетащи **всё содержимое** этой папки (включая скрытую папку `.github`). Если браузер не видит `.github`, создай файл вручную: *Add file → Create new file* → имя `.github/workflows/build-windows.yml` → вставь текст из этого файла.
3. Вкладка **Actions** → сборка запустится сама (~8–10 мин). Когда загорится зелёная галочка — открой её и скачай **Driftwood-Windows-VST3** внизу страницы.
4. Внутри: `Driftwood.vst3` (плагин) и `Driftwood.exe` (отдельное приложение для теста).

### Вариант B — собрать у себя
1. Установи **Visual Studio 2022 Community** (компонент «Разработка классических приложений на C++»), **CMake** и **Git**.
2. Двойной клик по `build_windows.bat`. Первая сборка скачает JUCE и займёт 5–10 минут.

## Установка в FL Studio
1. Скопируй папку **`Driftwood.vst3`** целиком в
   `C:\Program Files\Common Files\VST3\`
2. FL Studio → **Options → Manage plugins** → **Find installed plugins** (или *Find more plugins*).
3. Найди **Driftwood** в списке, поставь звёздочку ⭐ (избранное) — он появится в браузере Plugin database → Generators.
4. Перетащи на канал Channel Rack. Пресеты: стрелки `< >` в шапке плагина или меню пресетов FL (иконка ▼ слева сверху окна плагина).

## Про VST2
VST2 Steinberg больше не распространяет (SDK закрыт с 2018), FL Studio полностью работает с VST3 — он и нужен.
Если у тебя есть старый VST2 SDK: `cmake -B build -DVST2_SDK_DIR=путь\к\VST2_SDK` → появится `Driftwood.dll`, его кладут в `C:\Program Files\Common Files\VST2\` (или в папку, указанную в настройках плагинов FL).

## Управление — фишки
- **Двойной клик** по ручке — сброс к значению по умолчанию. При вращении показывается точное значение.
- **Наведи курсор** на любую ручку — подсказка на русском, что она делает.
- **Колесо модуляции** (CC1) добавляет вибрато, **sustain-педаль** (CC64) работает, **pitch bend** — диапазон ручкой BEND.
- Индикатор **LFO** мигает в такт, точки рядом — активные голоса, справа — осциллограф.
